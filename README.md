# 随机成长RPG - 终极网页版

一个功能丰富、视觉效果出色的网页版角色扮演游戏，融合了装备系统、角色养成、技能系统和回合制战斗，提供沉浸式的游戏体验。

## 🎮 游戏特色

### 核心玩法
- **角色养成**：通过分配属性点和养成系统提升角色能力
- **装备系统**：武器、防具、饰品、护符四大类装备，多种品质等级
- **技能系统**：多种技能类型，包括伤害、治疗和减益效果
- **战斗系统**：回合制战斗，实时伤害计算和动画效果
- **队伍系统**：最多可配置4名角色组成队伍
- **关卡挑战**：逐步提升难度的关卡设计
- **图鉴系统**：收集角色和怪物信息
- **背包系统**：管理和使用各种物品

### 视觉效果
- **现代化UI**：采用渐变色彩和霓虹发光效果
- **流畅动画**：技能特效、伤害数字、战斗反馈等丰富动画
- **响应式设计**：适配桌面端和移动端
- **动态背景**：流动渐变背景，增强游戏氛围
- **战斗特效**：技能释放、怪物受击、暴击等多种视觉反馈

### 技术特色
- **纯前端实现**：使用HTML5、CSS3和JavaScript开发
- **本地存储**：游戏进度自动保存到本地
- **模块化代码**：清晰的代码结构，易于维护和扩展
- **性能优化**：硬件加速和动画优化
- **事件驱动**：响应式的用户交互设计

## 📖 游戏系统详解
### 角色养成
- 等级提升 ：通过战斗获得经验值，提升等级
- 属性分配 ：每级获得属性点，可分配到攻击、防御和生命
- 养成系统 ：使用金币提升各项属性，包括生命、攻击、防御、暴击率等
- 角色管理 ：可配置最多4名角色组成队伍
### 装备系统
- 装备类型 ：武器（攻击）、防具（防御）、饰品（特殊属性）、护符（辅助属性）
- 装备洗炼 ：消耗金币重新生成装备属性，获得更好的属性组合
- 装备品质 ：从凡品到神话，品质越高属性越好
- 装备管理 ：通过背包和装备列表管理所有装备
### 技能系统
- 技能类型 ：伤害技能、治疗技能、减益技能
- 技能冷却 ：使用技能后进入冷却时间
- 技能效果 ：不同技能有不同的特效和动画
- 职业技能 ：不同职业拥有专属技能
### 战斗系统
- 回合制 ：玩家和怪物轮流行动
- 伤害计算 ：基于攻击力、防御力和技能倍率
- 战斗反馈 ：实时显示伤害数字和战斗状态
- 战斗策略 ：可选择使用技能或普通攻击
### 关卡系统
- 关卡递进 ：难度逐渐提升
- 重复挑战 ：可重复挑战已通过的关卡
- 第一关 ：快速返回初始关卡，适合刷经验和装备
### 背包系统
- 物品管理 ：查看、使用和管理背包中的物品
- 物品分类 ：自动分类武器、防具、饰品和护符
- 物品使用 ：直接在背包中使用物品
### 图鉴系统
- 怪物图鉴 ：记录已遇到的怪物信息
- 收集奖励 ：收集一定数量的图鉴可获得奖励
## 💾 游戏数据
游戏进度会自动保存到浏览器的本地存储中，包括：

- 角色等级、经验和属性
- 装备和背包物品
- 游戏统计数据
- 已解锁的图鉴
- 游戏设置和偏好
