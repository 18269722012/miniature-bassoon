# 随机成长RPG（终极网页版）

一个功能丰富、视觉效果出色的网页版角色扮演游戏，融合了装备系统、角色养成、技能系统和回合制战斗。

## 🎮 游戏特点

### 核心玩法
- **角色养成**：通过分配属性点提升角色能力
- **装备系统**：武器、防具、饰品三大类装备，多种品质等级
- **技能系统**：多种技能类型，包括伤害、治疗和减益效果
- **战斗系统**：回合制战斗，实时伤害计算和动画效果
- **关卡挑战**：逐步提升难度的关卡设计
- **图鉴系统**：收集角色和怪物信息

### 视觉效果
- **现代化UI**：采用渐变色彩和霓虹发光效果
- **流畅动画**：技能特效、伤害数字、战斗反馈等丰富动画
- **响应式设计**：适配桌面端和移动端
- **动态背景**：流动渐变背景，增强游戏氛围

### 技术特色
- **纯前端实现**：使用HTML5、CSS3和JavaScript开发
- **本地存储**：游戏进度自动保存到本地
- **模块化代码**：清晰的代码结构，易于维护和扩展
- **性能优化**：硬件加速和动画优化

## 🚀 如何开始

1. **直接打开**：在浏览器中打开 `index.html` 文件即可开始游戏
2. **本地服务器**：推荐使用本地服务器运行以获得最佳体验

## 📖 游戏系统说明

### 角色养成
- **等级提升**：通过战斗获得经验值，提升等级
- **属性分配**：每级获得属性点，可分配到攻击、防御和生命
- **装备强化**：通过洗炼系统获得更好的装备属性

### 装备系统
- **装备类型**：武器（攻击）、防具（防御）、饰品（特殊属性）
- **品质等级**：从凡品到神话，品质越高属性越好
- **装备洗炼**：消耗金币重新生成装备属性

### 技能系统
- **技能类型**：伤害技能、治疗技能、减益技能
- **技能冷却**：使用技能后进入冷却时间
- **技能效果**：不同技能有不同的特效和动画

### 战斗系统
- **回合制**：玩家和怪物轮流行动
- **伤害计算**：基于攻击力、防御力和技能倍率
- **战斗反馈**：实时显示伤害数字和战斗状态

### 关卡系统
- **关卡递进**：难度逐渐提升
- **重复挑战**：可重复挑战已通过的关卡
- **第一关**：快速返回初始关卡

## 💾 游戏数据

游戏进度会自动保存到浏览器的本地存储中，包括：
- 角色等级和经验
- 装备和属性分配
- 游戏统计数据
- 已解锁的图鉴

## 🎨 游戏界面

- **图鉴界面**：查看已收集的角色和怪物信息

## 🔧 游戏设置

- **音效开关**：控制游戏音效

## 📱 兼容性
